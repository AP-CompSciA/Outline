# Grading

## Assessments

* Tests
    * Mini AP
        * MCQs
        * FRQs
* Problem Set
* Oral Exams
    * **Easy:** Ask **3 of 8**
    * **Medium:** Ask **3 of 8**
    * **Hard:** Ask **2 of 8**
    * About **8 questions total**, 8–12 minutes per student.

## Schemes

### General

| Level | Points | Description |
| --- | :---: | --- |
| 🟩 **Green** | **3** | Demonstrates complete understanding. Answer is accurate and clear with no errors. |
| 🟨 **Yellow** | **2** | Demonstrates partial understanding. Answer is mostly correct but may contain minor errors, omissions, or require prompting. |
| 🟥 **Red** | **1** | Demonstrates little or no understanding. Answer is incorrect, incomplete, or difficult to follow. |
| ⬜&nbsp;**Incomplete** | — | Assessment was not completed. May be reassessed according to class policy. |

### Oral Exam

| Level | Points | Description |
| --- | :---: | --- |
| 🟩 **Green** | **3** | Demonstrates complete understanding. Explanation is accurate, clear, and uses appropriate computer science terminology. Explains *why* the code or concept works, answers follow-up questions confidently, and communicates reasoning effectively. |
| 🟨 **Yellow** | **2** | Demonstrates partial understanding. Explanation is mostly correct and understandable but may contain minor errors, omissions, or require hints or prompting. Can explain some reasoning but struggles with follow-up questions. |
| 🟥 **Red** | **1** | Demonstrates little or no understanding. Explanation is incorrect, incomplete, or difficult to follow. Unable to explain *why* the code or concept works, even with prompting. |
| ⬜&nbsp;**Incomplete** | — | Assessment was not completed. May be reassessed according to class policy. |
